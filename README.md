# Elliott Wave Project

Автоматический волновой анализ по Эллиоту с подключением к MetaTrader 5.

**Текущий статус:** ✅ 194 теста, 90% покрытие

---

## 📋 Что умеет

### Волновые паттерны (по traderevolution.by)
- ✅ **Импульсы** (1-2-3-4-5) с проверкой правил Эллиота
- ✅ **Диагонали** (Leading/Ending, Contracting/Expanding)
- ✅ **Коррекции** (зигзаг, 3 типа плоскости, 3 типа треугольника)
- ✅ **Комбинации** (W-X-Y, W-X-Y-X-Z)
- ✅ **Растяжение** (W1, W3, W5) с полными правилами
- ✅ **Усечение** (Truncated 5th) + визуальные паттерны
- ✅ **Выбросы/недобои** в диагоналях
- ✅ **Чередование** (W2↔W4, A↔B)

### Фибоначчи
- ✅ Сетка коррекции (W2, W4, W_B)
- ✅ Расширение импульса (W3, W5, W_C)
- ✅ W4 vs W2
- ✅ Диагонали (суж./расш.)
- ✅ Кластеры уровней
- ✅ Ортодоксальные точки (все паттерны)

### Дивергенция MACD/AO
- ✅ W3/W5 (импульсы)
- ✅ A/C (зигзаги, плоскости)
- ✅ W/Y (двойные тройки)

### Мультитаймфреймовый анализ (MTF)
- ✅ M15 / H1 / H4 / D1 / W1
- ✅ Определение текущей волны на каждом ТФ
- ✅ Глобальный тренд (EMA)
- ✅ Панель в консоли и на графике

### Визуализация
- ✅ Чистая структура (без свечей)
- ✅ Уровни Фибо с подписями
- ✅ Кластеры (золотые зоны)
- ✅ MTF-панель
- ✅ Сохранение в PNG

## 🛠 Установка

### Требования
- Windows 10/11
- Python 3.12 (или 3.11)
- MetaTrader 5 (установлен и запущен)

### Шаги

1. **Клонировать репозиторий:**
```powershell
git clone <URL_репозитория> C:\projects\elliott_wave_project
cd C:\projects\elliott_wave_project
Создать виртуальное окружение:

powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
Установить зависимости:

powershell
pip install -r requirements.txt
Проверить тесты:

powershell
python run_tests.py
🚀 Использование
Анализ одного таймфрейма
powershell
python main_mpl.py --tf H4 --show 5
Параметры:

--tf — таймфрейм (M15, H1, H4, D1, W1)

--symbol — символ (по умолчанию EURUSD)

--candles — количество свечей (по умолчанию 500)

--zigzag — длина ZigZag (по умолчанию 5)

--show — сколько паттернов показывать (по умолчанию 5)

--no-filter — отключить фильтр наложений

--no-fib — отключить уровни Фибоначчи

MTF-анализ
powershell
python main_mpl.py --mtf --candles 300
Показывает панель со всеми 5 таймфреймами.
